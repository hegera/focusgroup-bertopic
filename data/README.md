# Data Directory

The dataset is not included in this repository to maintain a single authoritative source.

## Download the Dataset

**📦 Download from Zenodo:** [https://doi.org/10.5281/zenodo.17798456](https://doi.org/10.5281/zenodo.17798456)

After downloading, place `data.csv` in this directory.

## Expected File Structure

```
data/
└── data.csv    (1,075 rows, 5 columns)
```

## Dataset Description

- **Rows:** 1,075 utterances from focus group discussions
- **Columns:**
  - `sentence`: Utterance text (French)
  - `participant`: Anonymized participant ID
  - `gender`: Participant gender
  - `region`: Anonymized region identifier  
  - `age`: Participant age (with missing values)
